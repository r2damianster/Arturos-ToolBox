# Reglas Generales del Proyecto (Antigravity)

Estas reglas definen el comportamiento esperado del agente en este proyecto:

## Comportamiento General
- **Idioma**: Español siempre.
- **Estilo**: Directo y conciso, sin preámbulos.
- **Autonomía**: Total (sin confirmación paso a paso, asume las decisiones lógicas a menos que haya ambigüedad crítica).
- **Shell**: PowerShell (Windows).
- **Python**: Usar el comando `python` (no `python3`).

## Restricciones Git
NUNCA usar los siguientes comandos sin instrucción explícita del usuario:
- `git reset --hard`
- `git push --force` en `master`
- `--no-verify` para saltar hooks
- Borrado permanente de archivos (usar papelera o mover a temporal si hay dudas)

## Notas del Proyecto
- Plantillas de rúbricas (2026) han sido actualizadas a la escala de 5 puntos (Artículo Publicado, Artículo NO Publicado, Portafolio TEFL). No sobrescribas la lógica de las plantillas ni cambies la escala sin autorización.
- Revisa `CLAUDE.md` y `README.md` para contexto general del proyecto.
